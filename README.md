<h1 align="center">🔥 HELL STORM 🔥</h1>

<h3 align="center"><em>A legendary memory scanner — built on the Cheat Engine engine, tuned for power and style.</em></h3>

<p align="center">
  <b>HELL STORM</b> is a customized build of <b>Cheat Engine</b> that keeps the exact same engine but adds a
  darker, fiercer identity, a stronger default scan profile, and an optimized AVX2 variant for modern CPUs.
</p>

<hr/>

<h2>⚡ New Features</h2>

<table align="center">
  <tr>
    <th>🔥</th>
    <th align="left">HELL STORM Identity</th>
    <td>Full rebrand: window title, taskbar name, menu entries, About screen and dialogs all show <b>HELL STORM</b>.</td>
  </tr>
  <tr>
    <th>🎨</th>
    <th align="left">Legendary Ember UI</th>
    <td>Bold fiery-orange process title that adapts automatically to dark/light mode, bold action buttons
        (<i>First Scan / Next Scan / Advanced Options / Table Extras</i>), bold "Found" counter and a fiery About screen.</td>
  </tr>
  <tr>
    <th>💪</th>
    <th align="left">Stronger Scan Coverage</th>
    <td>Scans <b>all memory regions by default</b> (Writable / Executable / CopyOnWrite = "don't care") — nothing gets missed.
        You can switch back anytime via right-click → Scan Region.</td>
  </tr>
  <tr>
    <th>⚡</th>
    <th align="left">Higher Scan Priority</th>
    <td>Scan threads default to a <b>higher priority</b> for noticeably faster scans.</td>
  </tr>
  <tr>
    <th>🚀</th>
    <th align="left">AVX2 Optimized Build</th>
    <td>A dedicated <code>cheatengine-x86_64-SSE4-AVX2.exe</code> build with <b>O4 optimization + AVX2</b> for modern CPUs.</td>
  </tr>
</table>

<h2>📦 Downloads / Builds</h2>

<p align="center">
  <code>bin/cheatengine-x86_64.exe</code> — Standard 64-bit build<br/>
  <code>bin/cheatengine-x86_64-SSE4-AVX2.exe</code> — Fastest build (requires AVX2-capable CPU, ~Intel Haswell 2013+ / AMD Ryzen)
</p>

<h2>🛠️ Build From Source</h2>

<ol>
  <li>Install <b>Lazarus 2.2.2 + FPC 3.2.2 (win64)</b> and the <b>i386 cross-compiler</b> add-on.</li>
  <li>Open <code>Cheat Engine/cheatengine.lpi</code> in Lazarus.</li>
  <li>Choose build mode <code>Release 64-Bit</code> (or <code>Release 64-Bit O4 AVX2</code>) and build (<kbd>Shift+F9</kbd>).</li>
</ol>
